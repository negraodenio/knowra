### 3. Orchestration Policy & Precedence

1. **Policy Version**: `EDUIA_POLICY_V1`
2. **Resolution Precedence**:
   - Explicit task environment variable (`TUTOR_MODEL`, `CLASSIFIER_MODEL`, etc.) has highest priority.
   - If unset, falls back to `DEFAULT_MODEL`.
   - If `DEFAULT_MODEL` is also unset, throws explicit `Error("Model not configured for task: ...")`.
   - Never randomly guesses or silently falls back to arbitrary models.

---

### 4. Operational Fallback Behavior

- **Eligible Failures**:
  - HTTP 500, 502, 503, 504 server errors
  - HTTP 429 rate limit exceeded
  - HTTP 404 endpoint not found / model temporarily unavailable
  - Network timeouts (`AbortError`, `TimeoutError`, `ECONNREFUSED`)
- **Non-Eligible Failures**:
  - Zod schema validation errors
  - JSON parse errors
  - Ordinary business rule rejections
- **Telemetry Record**:
  - `fallbackUsed: true`
  - `fallbackModel: "<model_id>"`
  - `fallbackReason: "<original_operational_error>"`
