## 1. Executive Summary & Non-Negotiable Architectural Principles

Knowra uses **Astra** (`openai/gpt-6-astra`) as its strategic primary model for all cognitively critical pedagogical reasoning. Sprint S7.8 introduces a high-performance **AI Response Cache** leveraging PostgreSQL and **pgvector** in Supabase, eliminating redundant LLM calls and minimizing latency while preserving pedagogical quality.

### Core Non-Negotiable Invariants:
1. **The Learning Engine is Unchanged**: The source of truth for learner mastery, knowledge gaps, diagnostic states, recommendations, Next Best Action, and spaced repetition is PostgreSQL learner state, **never** the AI Cache.
2. **AI Cache is an Optimization Layer Only**: The cache answers only *"Can this previously validated response safely be reused?"*. It never decides model strategy or pedagogical progression.
3. **Strict Model Compatibility**: A cache entry created by `openai/gpt-6-astra` can **never** satisfy a request for another model, and a cheaper model response can **never** silently replace Astra.
4. **Failure Resilience**: If Supabase cache lookup, pgvector matching, or embedding generation encounters any glitch or timeout, the system logs a warning, emits telemetry, and immediately falls through to the normal AI Orchestrator / Gateway. Cache failure **never breaks learning**.
5. **Zero Redis / External Vector DBs**: The architecture remains simple and unified within the existing Supabase PostgreSQL instance using native `vector(1536)` and HNSW indexing.

## 3. L1 Exact Cache & Canonicalization

### Canonicalization Algorithm (`lib/ai/cache/canonicalize.ts`):
1. **Deep Recursive Sorting**: Object keys are sorted alphabetically at every nesting level so `{ a: 1, b: 2 }` and `{ b: 2, a: 1 }` serialize identically.
2. **Whitespace Normalization**: Trims leading/trailing whitespace and standardizes CRLF to LF without destroying code indentation.
3. **Excluded Volatile Fields**: Timestamps, random seeds, and ephemeral request IDs are strictly excluded.
4. **Included Key Dimensions**:
   - `task`: Casing-normalized task name (`tutor`, `material`, etc.)
   - `model`: Exact requested model identifier (`openai/gpt-6-astra`)
   - `modelVersion`: Model version or null
   - `promptVersion`: Exact prompt template version
   - `schemaVersion`: Zod schema version
   - `policyVersion`: Active orchestrator policy version (`EDUIA_POLICY_V2`)
   - `normalizedInput`: Sanitized input text
   - `domainId`: Target curriculum domain
   - `competencyId`: Target competency ID
   - `scope`: `SHARED` or `USER_CONTEXTUAL`
   - `userId`: Bound only when `scope == 'USER_CONTEXTUAL'`
5. **Key Generation**: `SHA-256(canonicalString)` produces a 64-character hexadecimal key stored with a `UNIQUE` constraint in `ai_response_cache.cache_key_hash`.

## 4. L2 Semantic Cache with pgvector

### Technical Implementation:
- **Verified Model**: `openai/text-embedding-3-small` (1536 dimensions) via OpenRouter.
- **Table Storage**: `public.ai_response_cache.embedding vector(1536)`.
- **Indexing**: Cosine distance HNSW index:
  ```sql
  CREATE INDEX idx_ai_cache_embedding_hnsw
    ON public.ai_response_cache
    USING hnsw (embedding vector_cosine_ops)
    WHERE embedding IS NOT NULL;
  ```
- **Stored Procedure (`match_ai_cache`)**:
  Enforces strict multi-attribute matching before cosine distance comparison:
  - Exact match on `task`, `model`, `prompt_version`, `schema_version`, `policy_version`.
  - Non-expired (`expires_at > now()`).
  - Validation status `VALIDATED` and quality status `PASSED`.
  - Scope match (`SHARED` or matching `user_id`).
  - Cosine similarity threshold >= 0.92 (conservative matching).

## 5. Cache Policy Matrix (`CACHE_POLICY_V1`)

| Task | Exact Cache | Semantic Cache | Scope | Default TTL | Similarity Threshold | Rationale |
|---|---|---|---|---|---|---|
| **TUTOR** | Yes | Yes (Shared) | `SHARED` | 30 Days | 0.92 | Shared conceptual explanations benefit from high reuse |
| **MATERIAL** | Yes | Yes (Shared) | `SHARED` | 14 Days | 0.92 | Instructional curriculum bites are highly reusable |
| **CLASSIFIER** | Yes | No | `SHARED` | 7 Days | 0.95 | High-frequency intent detection; exact hash lookup is sufficient |
| **DIAGNOSTIC** | Yes (Contextual) | No | `USER_CONTEXTUAL` | 24 Hours | 0.98 | Bound to specific learner state; cross-user matching strictly prohibited |
| **COMPETENCY** | Yes | No | `SHARED` | 30 Days | 0.95 | Static formal competency definitions |
| **FEYNMAN** | **No** | **No** | `DISABLED` | 0 | 1.00 | Freeform explanations are unique per learner; fresh scoring required |
| **ASSESSMENT** | **No** | **No** | `DISABLED` | 0 | 1.00 | Assessment items must be freshly generated to prevent question leakage |
| **PLAN** | **No** | **No** | `DISABLED` | 0 | 1.00 | Plans depend directly on dynamic prerequisite gap analysis |

### Non-Cacheable Entities (Permanent Invariant):
The following are **never** cached as AI responses:
- `learning_state`
- `mastery`
- `confidence`
- `gaps`
- `recommendations`
- `next_best_action`
- `evidence`
- `retention`
- `learning_gain`

## 6. Security, RLS & Cross-User Isolation

1. **Row Level Security (RLS)**:
   - Enabled on `public.ai_response_cache`.
   - Full access granted to `service_role` (used server-side by AI Gateway).
   - Authenticated learners may only read `scope = 'SHARED'` or their own `scope = 'USER_CONTEXTUAL'` rows (`user_id = auth.uid()`).
2. **Contextual Isolation**:
   - `ai_response_cache.user_id` is bound to `auth.users(id)`.
   - Contextual lookups require matching `userId`. If user A requests a cached response belonging to user B, the cache treats it as a strict miss.

## 7. Cost Savings & Observability Telemetry

Every cache hit captures avoided cost and latency savings:
```typescript
interface AIUsageRecord {
  cacheEnabled: boolean;
  cacheHit: boolean;
  cacheLayer: "L1_EXACT" | "L2_SEMANTIC" | "NONE";
  cacheKeyHash?: string;
  semanticSimilarity?: number;
  cacheLatencyMs: number;
  actualLlmCall: boolean;
  llmCallsAvoided: number;
  estimatedCostSaved: number;
  primaryModel: string;
  selectedModel: string;
}
```

### Savings Calculation:
Avoided cost is calculated using `KNOWN_MODEL_PRICING` for the requested model:
- For `openai/gpt-6-astra`: $10.00 / 1M prompt tokens, $50.00 / 1M completion tokens.
- On exact hit: avoided cost = ~$0.0155 per avoided call.
- Latency reduced from ~7,700ms (Astra live inference) to **112ms** (L1 Exact) and **999ms** (L2 Semantic with embedding).
