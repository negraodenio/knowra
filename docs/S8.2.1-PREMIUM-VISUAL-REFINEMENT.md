# S8.2.1 — Knowra Premium Visual Refinement Documentation

## 1. Objective
Transform the Knowra public landing page (`app/components/landing-page.tsx`), authentication modal (`app/components/auth-modal.tsx`), and standalone authentication screen (`app/auth/page.tsx`) from a conventional SaaS / EdTech presentation into a **luxury, minimal, sophisticated, editorial technology experience**.

The visual language follows the design disciplines of **Apple-level restraint**, **Linear-level precision**, **private financial technology**, and **high-end consulting**, communicating quiet confidence rather than startup hype.

---

## 2. Core Visual Principles
1. **Restraint over Decoration**: No neon blobs, glowing borders, rainbow gradients, particle animations, or marketing buzzwords.
2. **Whitespace as Structure**: Generous padding (`py-28`, `py-36`, `gap-16`) letting editorial headlines and technical data breathe naturally.
3. **95% Neutral / 5% Accent Palette**:
   - Deep background: `#07090e` / `#0a0d14`
   - Surfaces & Borders: `#0c1018`, border opacity `border-white/[0.08]`
   - High-contrast Typography: Crisp white `#ffffff` headings and muted zinc `#a1a1aa` / `#71717a` body text
   - Restrained Accent: Knowra emerald (`emerald-400`/`emerald-500`) applied strictly to live telemetry indicators, active states, and focused interaction cues.
4. **Editorial & Precision Typography**:
   - Monospaced technical tags (`font-mono text-xs uppercase tracking-widest text-zinc-400`)
   - Balanced, non-oversized editorial headlines with controlled tracking
5. **Quiet Product Evidence**: Illustrative learning states clearly labeled `ILLUSTRATIVE SPECIFICATION`, demonstrating precision without fabricating user numbers.

## 4. Key Changes Made by Section

### Navigation
- Minimal header with subtle blur (`backdrop-blur-md bg-[#07090e]/85`), thin border (`border-white/[0.06]`).
- Clean typography: `KNOWRA` logotype with monospaced indicator `ENGINE v8.2`.
- Direct links: `How it works`, `Curriculum`, `Sign in`, and crisp primary CTA `Start Learning →`.

### Hero Section
- Bold, restrained headline:
  ```
  LEARN WHAT YOU NEED.
  NOT WHAT EVERYONE ELSE GETS.
  ```
- Clear, unhyped subheadline explaining the adaptive engine.
- Single primary CTA (`Start Learning →`) paired with quiet secondary anchor link (`See the mechanics ↓`).

### Intelligence Instrument (Hero Visual)
- Minimalist hardware-inspired panel labeled `KNOWRA // LEARNING STATE SPECIFICATION — ILLUSTRATIVE EXAMPLE`.
- Displays real curriculum competencies (Python: Variables, Control Flow, Functions) with precise status badges (`STRONG`, `DEVELOPING`, `NEEDS ATTENTION`).
- Highlights Next Best Action with exact rationale and evidence requirement.

### Editorial Problem Contrast
- Text statement: *"Most learning platforms know what you did. Knowra focuses on what you know."*
- Side-by-side monochrome comparison of platform tracking vs. Knowra cognitive modeling.

### Narrative Architecture (Differentiation)
- Deconstructed the traditional comparison table into an architectural narrative:
  - **The Conventional Pipeline**: Content → Sequence → Completion (Passive consumption)
  - **The Knowra Engine**: Goal → Knowledge State → Evidence → Mastery → Next Best Action (Active inference)

### The 7-Stage Adaptive Loop
- Ordered editorial steps (`01` through `07`): Goal Formulation, Baseline Calibration, Knowledge State, Next Best Action, Evidence Production, Mastery Recalculation, Continuous Adaptation.
- Monospaced numbering, bold titles, concise explanatory prose.

### Product Philosophy Moment
- Full-width editorial statement:
  ```
  COMPLETION
  IS NOT
  MASTERY.
  ```
- Subtext: *"An activity can be completed. A lesson can be finished. None of those alone proves competence."*
- Concrete 4-phase transformation: `Activity → Evidence → Mastery → Retention`.

### Curated Domain Index
- Editorial directory for `01 / Python Foundations`, `02 / Mathematics for Exams`, `03 / Excel for Professionals`.
- Displays exact competency counts and target outcomes without LMS clutter.

### Minimal Final CTA
- Crisp headline: `STOP GUESSING WHAT TO LEARN NEXT.`
- Single action button leading to goal onboarding or authentication.

  - `landing_viewed`
  - `landing_how_it_works_clicked`

  - `signup_started`
- **Learning Engine Integrity**: S1–S7.8 engines, Astra-first model (`openai/gpt-6-astra`), AI Cache with pgvector, and Supabase RLS policies remain untouched.
- **No Extra Dependencies**: Reused existing Tailwind and React stack without introducing new CSS or JavaScript animation libraries.
