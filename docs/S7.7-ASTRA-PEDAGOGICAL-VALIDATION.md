## 1. Executive Summary & Non-Negotiable Product Decision

EDUIA is a personalized adaptive learning platform whose pedagogical efficacy relies on high-quality cognitive reasoning, conceptual diagnostics, misconception remediation, and curriculum planning. 

In Sprint S7.6, an empirical model benchmark incorrectly promoted `openai/gpt-4o-mini` to the default model because it was the fastest and cheapest candidate to run. **That was an error and is formally revoked.** EDUIA does not optimize for the lowest token price; EDUIA optimizes for the **highest learning outcome per unit cost**.

### Strategic Decision: ASTRA-FIRST

1. **Strategic Primary Model**: **Astra** (`openai/gpt-6-astra`) is established as the primary, high-capability default model for all cognitively critical AI tasks across the platform.
2. **Operational Fallback**: `openai/gpt-4o-mini` serves strictly as an infrastructure-level fallback during network timeouts, HTTP 429/5xx, or provider unavailability. Operational fallback **never** alters the strategic default model.
3. **Control Plane Preserved**: The AI Model Orchestrator (`lib/ai/orchestrator.ts`) remains the single control plane responsible for task classification, pedagogical requirement profiling, model routing, error classification, and telemetry.
4. **No Fabricated Model IDs**: The live OpenRouter provider catalog was queried and the real endpoint verified as `openai/gpt-6-astra`.

## 3. Orchestration Policy: `EDUIA_POLICY_V2`

`lib/ai/orchestrator.ts` executes routing according to the following rules:

### A. Cognitively Important Tasks
- **Tasks**: `TUTOR`, `FEYNMAN`, `DIAGNOSTIC`, `ASSESSMENT`, `PLAN`, `COMPETENCY`.
- **Policy**:
  1. Check task-specific environment override (e.g., `TUTOR_MODEL`).
  2. If unset, resolve `EDUIA_PRIMARY_MODEL` (`openai/gpt-6-astra`).
  3. If unconfigured, throw an explicit error. **Never** substitute a cheaper model.

### B. Low-Risk Tasks
- **Tasks**: `CLASSIFIER`, `MATERIAL`.
- **Policy**:
  1. Check task-specific environment override (`CLASSIFIER_MODEL`, `MATERIAL_MODEL`).
  2. If unset and policy approves a cheaper model (e.g. `openai/gpt-4o-mini` for intent classification), route to the cheaper model.
  3. Otherwise resolve `EDUIA_PRIMARY_MODEL`.

### C. Operational Fallback Discipline
- Fallback triggers **only** for infrastructure failures: HTTP 429, 500, 502, 503, 504, 404 endpoint missing, connection reset, connection refused, or timeout.
- Fallback **never** triggers for business or validation failures: Zod schema errors, JSON parse failures, pedagogical content failures, or rubric misses.
- Telemetry explicitly flags `fallbackUsed: true`, records `fallbackModel`, and retains `primaryModel` for complete auditability.

## 5. Live Empirical Benchmark Findings

The live validation script (`scripts/run-astra-pedagogical-benchmark.ts`) was executed against live OpenRouter endpoints.

### Qualitative Analysis: Why Astra Is Preferred for Cognitive Tasks

1. **Misconception Depth**: On Feynman evaluation, Astra identified 5 distinct underlying misconceptions (e.g. *"Assignment can make multiple names refer to the same object"* and *"Mutating an object differs from rebinding a variable"*), while Mini provided generic definitions.
2. **Pedagogical Assessment Items**: In assessment item generation, Astra formulated a realistic code snippet testing shallow list copying (`copy = original[:]`) and mutable element modification (`copy[0].append(3)`), which accurately discriminates conceptual mastery. Mini generated simple string questions.
3. **Curriculum Sequencing**: In learning plan formulation, Astra sequenced prerequisite competencies from foundational primitive types to collections, indexing, and functional abstraction.
