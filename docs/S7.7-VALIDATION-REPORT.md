## 1. Executive Summary & Strategic Correction

Sprint S7.7 corrects the platform's strategic AI model direction. In previous sprint S7.6, `openai/gpt-4o-mini` was mistakenly proposed as default because it was the easiest model to empirically benchmark. That was not the product decision:

1. **Strategic Principle**: EDUIA is not optimizing for the cheapest LLM; EDUIA optimizes for the **highest learning gain per unit cost**. Astra is the strategic primary model for all cognitively critical tasks.
2. **Endpoint Verification**: The live OpenRouter provider catalog was queried and the real endpoint verified as **`openai/gpt-6-astra`** (1,050,000 context, reasoning-capable).
3. **Live Pedagogical Benchmark**: Astra was successfully called and evaluated across 8 EDUIA workloads using deterministic pedagogical rubrics (`Tutor`, `Feynman`, `Diagnostic`, `Assessment`, `Plan`, `Competency`, `Material`, `Classifier`).
4. **Orchestrator Intact**: `lib/ai/orchestrator.ts` remains the control plane (`EDUIA_POLICY_V2`), routing cognitively critical tasks to `EDUIA_PRIMARY_MODEL` (`openai/gpt-6-astra`) and low-risk tasks (`CLASSIFIER`) to policy-approved cheaper models (`openai/gpt-4o-mini`).
5. **Operational Fallback Separate**: Operational fallback is strictly isolated to infrastructure errors (HTTP 429, 5xx, timeouts, connection drop). Fallback never redefines strategic model selection and never masks schema or pedagogical failures.
6. **No Regressions**: All 212 tests pass, typecheck is clean, ESLint is clean, and Next.js production build succeeds across all 15 routes.

## 7. Final Routing & Fallback Policy

### Policy Version: `EDUIA_POLICY_V2`

1. **Strategic Primary**:
   ```env
   EDUIA_PRIMARY_MODEL=openai/gpt-6-astra
   ```
2. **Operational Fallback**:
   ```env
   FALLBACK_MODEL=openai/gpt-4o-mini
   ENABLE_OPERATIONAL_FALLBACK=true
   ```
3. **Task Routing Rules**:
   - Cognitively Important Tasks (`TUTOR`, `FEYNMAN`, `DIAGNOSTIC`, `ASSESSMENT`, `PLAN`, `COMPETENCY`):
     - Route to `task override` if set.
     - Otherwise route to `EDUIA_PRIMARY_MODEL` (`openai/gpt-6-astra`).
     - If `EDUIA_PRIMARY_MODEL` is unconfigured, throw explicit error. **Never** silently fallback.
   - Low-Risk Tasks (`CLASSIFIER`, `MATERIAL`):
     - Route to `task override` if set (e.g., `CLASSIFIER_MODEL=openai/gpt-4o-mini`).
     - Policy-approved cheaper model allowed for `CLASSIFIER`.
     - Otherwise route to `EDUIA_PRIMARY_MODEL`.
4. **Fallback Trigger Criteria**:
   - **Permitted**: Network timeouts, connection resets, DNS failures, HTTP 429 rate limit, HTTP 500, 502, 503, 504, HTTP 404 endpoint missing.
   - **Strictly Prohibited**: JSON parsing error, Zod schema validation mismatch, rubric score failure.
