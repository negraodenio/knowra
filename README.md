# Knowra

> The Learning Engine that knows what you know.

Knowra is an Adaptive Learning Intelligence platform designed to understand what a learner actually knows, identify knowledge gaps, measure mastery and confidence, and determine the best next learning action.

Knowra is not an LMS.
It is not a generic AI chatbot.

It combines structured learning state, evidence, mastery, confidence, prerequisite relationships, adaptive recommendations, Feynman evaluation and spaced repetition into a continuous learning loop.

## Core Thesis

> LLMs know things.
> The Learning Engine knows what the learner knows — and what they should do next.
